# Shadow Of Optimization

> Pure performance-focused Fabric 1.21.11 modpack. No visuals, no gameplay changes, no new content. Only optimization.
> Чисто оптимизационная сборка на Fabric 1.21.11. Никакого визуала, никаких изменений геймплея, никакого нового контента. Только оптимизация.

## About / О проекте

**EN:** Shadow Of Optimization is a pure performance-focused Fabric 1.21.11 modpack. No visuals, no gameplay changes, no new content. Only optimization. The goal is simple: maximum FPS and stability on any hardware, from weak laptops to high-end PCs. Every mod in this pack exists for one reason — to make Minecraft run faster and smoother without changing the game itself.

**RU:** Shadow Of Optimization — это чисто оптимизационная сборка на Fabric 1.21.11. Никакого визуала, никаких изменений геймплея, никакого нового контента. Только оптимизация. Цель простая: максимальный FPS и стабильность на любом железе, от слабых ноутбуков до топовых ПК. Каждый мод в этой сборке существует ради одного — сделать Minecraft быстрее и плавнее, не меняя саму игру.

## Performance / Производительность

**EN:** The pack is built around Sodium, Lithium, FerriteCore, Krypton, ImmediatelyFast, EntityCulling, More Culling, Dynamic FPS, FastQuit, SmoothBoot, BadOptimizations, Circular Rendering, Clumps and Chunky.

Even on weak hardware it delivers stable high FPS at reasonable render distance. Chunky allows you to pre-generate the world — after that, stutters disappear completely.

**RU:** Сборка построена вокруг Sodium, Lithium, FerriteCore, Krypton, ImmediatelyFast, EntityCulling, More Culling, Dynamic FPS, FastQuit, SmoothBoot, BadOptimizations, Circular Rendering, Clumps и Chunky.

Даже на слабом железе даёт стабильный высокий FPS при разумной дальности прорисовки. Chunky позволяет предгенерировать мир — после этого лаги исчезают полностью.

## Installation / Установка

**EN:**
1. Install Fabric Loader for Minecraft 1.21.11
2. Download the modpack release from the Releases page
3. Place all mods into your `mods` folder
4. Allocate 3-4 GB of RAM in your launcher
5. Launch the game

**RU:**
1. Установи Fabric Loader для Minecraft 1.21.11
2. Скачай релиз сборки со страницы Releases
3. Помести все моды в папку `mods`
4. Выдели 3-4 ГБ ОЗУ в лаунчере
5. Запусти игру
